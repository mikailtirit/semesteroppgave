# IT Asset Management System (ITAM)

## Konsept 
Dette er et system for at it-avdelinger, skoler eller bedrifter skal kunne holde kontroll på alt sitt digitale utstyr. Systemet skal gjøres det enkelt å registrere enheter (PC-er,mobiler, servere), koble dem til brukere og loggføre reperasjoner og vedlikehold. 

### kompetansemål
Prosjektet dekker mål i alle tre hovedfag
* **utvikling** lage frontend (html/css) og backend (Python/Flask) med en database (SQlite )
